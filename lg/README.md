# LG 49UJ620V-ZA (2017, webOS)

SSDP: `[LG] webOS TV UJ620V`, DMR (1836) и DIAL (1468). Порты: 3000/3001 (сетевой пульт SSAP) — открыты после
включения «LG Connect Apps»/мобильного подключения; 9922 (режим разработчика) и 22 закрыты; 9998 — отладочный
интерфейс встроенного Chromecast (штатный сервис, не используется).

`lg_remote.py` — клиент SSAP на стандартной библиотеке: `info`, `raw <uri> [json]`, `key <HOME|MENU|UP|DOWN|…>`.
Ключ сопряжения пишется в `lg_key.txt` (не коммитится). Подключение **без подписанного манифеста LG**: телевизор
спрашивает «Разрешить» и даёт только права, не требующие подписи.

Проверено на этом ТВ: `createToast` (всплывающее сообщение), `getForegroundAppInfo` (сейчас `com.webos.app.livetv`),
`getPowerState`, кнопки пульта через pointer-socket. **Не работает без подписи** (401): `listApps`, `listLaunchPoints`,
`getCurrentSWInformation`, `getSystemSettings` — поэтому список приложений и точную версию webOS отсюда не узнать
(прошивка со слов владельца 06.10.75).

ADB нет, SSH нет. Что реально: настройки с пульта (реклама, LivePlus, «Быстрый запуск+»), DNS на роутере/ТВ.
