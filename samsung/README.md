# Samsung UE55NU7170 (2018, Tizen)

`18_KANTME_UHD_BASIC`, Tizen, по кабелю. ADB нет (5555 закрыт), режима разработчика нет (26101 закрыт) — отключать
системные приложения и ставить свой лаунчер нельзя (см. CleanYourTV `docs/devices/samsung-tizen.md`).
Открыты 8001/8002 (API и сетевой пульт), 8080, 9197 (DMR), 7678.

- `samsung_remote.py` — сетевой пульт (TLS websocket 8002, только стандартная библиотека):
  `python3 -I samsung_remote.py <ip> KEY_MENU KEY_DOWN KEY_ENTER`. Первое подключение спрашивает «Разрешить» на ТВ,
  токен пишется в `samsung_token.txt` (не коммитится). Экрана не видно — только с человеком у телевизора.
- Меню этой прошивки: слева Изображение, Звук, Трансляция, Общие, Поддержка. В «Поддержке»: Обновление ПО,
  Самодиагностика, e-Manual, Запросить поддержку, Удалённое управление, Об этом телевизоре — пункта «Условия и
  политика» там нет. Рекламу/слежку и автозапуск Smart Hub владелец выключил сам с пульта (24.10.2026).
