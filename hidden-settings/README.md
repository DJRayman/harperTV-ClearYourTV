# Скрытые настройки

Небольшое приложение для Android TV (17 КБ, без библиотек): список экранов настроек, которых нет в обычном меню,
OK открывает выбранный. Пункты, которых нет на устройстве (или которые закрыты для сторонних приложений), не
показываются, поэтому одна сборка подходит и проектору, и телевизорам.

Разделы (`Catalog.java`):
- **Проектор (Jixin, `com.jixin.settings5`)** — режим проекции, трапеция и фокус, коррекция по 4 углам (2 варианта),
  масштаб, режим яркости (диалог и экран), режимы изображения, скрытые диалоги пульта (изображение и звук,
  быстрое меню), источник при включении, выбор источника, голос, часы, заставка, подсветка, «звёздное небо».
- **Изображение и звук (Amlogic, `com.droidlogic.tv.settings`)** — подробный режим изображения, AI-улучшение,
  звук, режим звука, DTS Virtual:X, тембр, баланс, громкость, HDMI-CEC, разрешение вывода, быстрые настройки,
  «Ещё», точка доступа.
- **Android TV (`com.android.tv.settings`)** — стандартное меню, которое прошивка заменила своим, «Для разработчиков»,
  экран и звук, приложения, неизвестные источники, заставка, дата, язык, клавиатура, входы, сеть, безопасность,
  об устройстве, состояние.

Специально не включены: сброс к заводским (`FactoryResetActivity`, `StorageResetActivity`), отладочные экраны,
закрытые (не экспортированные) экраны вроде `DebugActivity` — их стороннее приложение запустить не может.
Dolby Audio убран: на проекторе T950S закрывается сразу (Dolby нет). Все остальные 43 экрана проверены запуском.

Сборка и установка:

    export JAVA_HOME=~/android/tools/jdk-21.0.12.1+1 PATH=$JAVA_HOME/bin:$PATH
    ./gradlew assembleDebug
    ~/android/adbw -s <ip>:<порт> install -r app/build/outputs/apk/debug/app-debug.apk
